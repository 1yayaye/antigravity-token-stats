# Antigravity IDE 版重构设计

状态：界面方案与核心实现已完成并在真实设备完成初轮验收；真实设备验收明细见 [hosts/antigravity-ide/README.md](../hosts/antigravity-ide/README.md)。

## 已确认目标

- 本次重构对象是项目的 Antigravity IDE 版本。
- 不以现有 IDE 界面的内容和布局为新版设计约束，重新设计 IDE 专属内容与信息架构。
- 取消现有侧边栏方案，入口位于 IDE 最底部状态栏，即 Tab Settings 所在行右侧。
- 状态栏设置三个独立组件：会话统计（`session`）、Token 用量（`tokens`）、上下文与额度（`context`），各自点击后向上弹出对应交互浮层（宽 368px，自适应视口）。
- 三个浮层的内容为 IDE 场景重新设计，不直接照搬桌面端浮层，也不采用此前未确认的统一「实时 / 历史」浮层方案。
- IDE 版只统计 IDE 自身的数据，不包含桌面端数据；两者数据独立。Token 用量汇总 IDE 全部项目、全部会话，不按当前项目筛选。
- 当前会话严格指当前 IDE 窗口正在查看的聊天；其他窗口的后台任务不替代该会话。无法可靠识别时明确显示未识别，不使用最近会话冒充。
- 周额度采用服务端数据；月额度保留现有四周推算，以估算利用率为主，详情注明 API 等值消耗和估算容量。历史不足时明确标注外推，缺少有效校准时显示暂无样本。
- 时间窗口按设备本地自然日计算：当日从零点开始，近七天包含今天及前六天，近三十天包含今天及前二十九天。
- 重建 IDE 内容、导航、布局与交互；现有采集、聚合和配额能力经过核查后复用，存在问题再替换。桌面版体验不随本次重构调整。
- 页面布局随产品内容一起重新设计。

## 三个组件的内容边界

| 组件 | 对应浮层的已确认内容 | 数据可用性边界 |
|---|---|---|
| 会话统计 | 当前可见聊天轮/步/采样数、模型/工具用时、平均 TTFT、会话/最近请求 TPS、正文与思考分项 | 不可识别时明确提示未识别，不用后台会话替代 |
| Token 用量 | 当前会话（或缺省时今日）缓存命中率与分项、今日 / 近 30 天 KPI，及可折叠展开的今日 / 近七天 / 近三十天三行分项明细表 | 思考不重复计入总量；缺失分项显示 — |
| 上下文与额度 | 上下文窗口（最近已记录请求、采样模型）+ 各实际额度池周剩余、重置时间与四周估算 | 无可信上限时不计算百分比；不跨池平均；额度缺失显示不可用，无校准显示暂无样本 |

三个入口顺序为会话统计、Token 用量、上下文与额度；浮层互斥并跟随原生主题，位置与高度适配窗口。此次范围不包含独立完整分析页。

## 已接受的界面方案

以下方案已由用户确认，作为本次实现与验收依据。

- 状态栏右侧连续放置三个组件，顺序为会话统计、Token 用量、上下文与额度（`['session', 'tokens', 'context']`），例如：`104.6 tok/s | 4.6K tok · 命中 71.4% | Ctx 50%`。
- 会话统计浮层展示当前可见聊天的模型/工具用时、平均 TTFT、会话与最近请求 TPS 以及正文/思考 Token。
- Token 用量浮层展示当前摘要与今日/近 30 天 KPI，并提供可折叠的今日、近七天、近三十天三行分项明细表（总量、输入、缓存、输出、其中思考；思考属于输出子项，避免重复累加）。
- 上下文与额度浮层上部展示最近已记录请求的上下文用量、可信上限与采样模型（上限不可信时仅显示已知 Token 数；生成期间保留最近采样），下部按实际额度池切换，分别展示周剩余比例、重置时间与四周估算（外推提示与无校准空状态）。
- 浮层统一采用一次只打开一个、再次点击当前入口关闭、点击其他入口切换、点击外部/跨 iframe 失焦或按 Esc 关闭的规则；键盘关闭后焦点返回触发入口。
- 视觉跟随 IDE 深浅主题，使用紧凑排版；浮层挂载于 `.monaco-workbench`（`z-index: 2500`）以正确覆盖跨进程聊天 iframe，位置与高度适配窗口边界，内容超高时内部滚动。

## 重构前核查与数据边界

以下记录重构前的实现与持续适用的数据限制，不作为新版布局约束；原生集成的交付状态以验收结果为准。

- 重构前的状态栏入口点击后打开侧边栏；新版替换为工作台内的三个入口与浮层。
- 重构前界面直接挂载共享的 `StatsView`；新版采用 IDE 专属组件与信息架构。
- 统计来源是 IDE 自己的数据目录，历史统计跨项目；现有数据契约没有项目身份或项目筛选。
- 重构前通过运行状态与会话开始时间推选当前会话，并使用固定上下文上限；新版绑定可见聊天路由，无可靠身份或上限时明确显示未知。
- 现有上下文展示针对最近一次已完成请求，并非生成过程中的实时占用；系统、工具、对话的细分使用固定基线估算。新版不能直接把这些估算分段作为实测数据沿用。
- 现有范围筛选与已确认的设备本地自然日口径一致，可以复用。
- 历史 Token 总量来自记录中的未缓存输入、缓存读取与输出，思考和回复已包含在输出中，不能再次累加。日期归属在原生时间戳缺失时会使用后备时间来源，可能影响具体日期的分配精度。
- 实时配额属于账户级数据，登录或请求失败时可能不可用。
- 当前额度契约仅捕获周额度。现有「月度」计算使用按周重置时间对齐的四个周期，本地历史不足时还会外推；其容量按推算周容量乘四计算。用户已确认保留该公式，展示估算利用率、外推质量提示和缺少校准的空状态。
- 现有四周估算将用户认证的远端周额度比例与本地 IDE API 等值消耗结合校准，二者统计范围不保证一致；仓库没有按账户和额度池保存的历史周额度快照。继续复用时必须明确这是基于本地历史的估算，不能标成实测月度额度。
- 重构前扩展目标及本地 API 类型版本为 VS Code 1.107。标准状态栏 API 未暴露自定义交互浮层挂载接口；已选择原生工作台注入来实现用户确认的交互。
- 原生交付通过 ESM 主入口加载独立宿主，在受限工作台页面注入 UI，复用现有 preload IPC；不改 preload 或 CSP。安装夹具与构建检查、真实设备的冷启动和重复启动分别验收。

## 决策树

- 入口结构与展开方向（已确认）：三个独立状态栏组件，分别点击后向上弹出对应浮层。
  - 公开 API 边界已核查；交付方式已选定为原生工作台注入，真实设备验证另行记录。
  - 摘要顺序、互斥浮层、外部点击与 Esc 关闭、键盘焦点返回、原生主题均已确认。
- 内容职责（已确认）：当前会话信息、周/月额度、当日/七天/三十天 Token 用量分别归属三个浮层。
  - 当前会话归属（已确认）：当前窗口正在查看的聊天；无法可靠识别时显示未识别。最近已记录请求与会话累计分项分开显示，无可信上限时不计算百分比。
  - 月额度口径（已确认）：保留四周估算公式、外推提示与无有效样本状态，不新增额度历史采集。
  - 时间窗口（已确认）：按设备本地自然日计算，三个范围同时显示，输入、缓存、输出和其中思考分项展示。
- 数据范围（已确认）：仅 IDE 数据，汇总其全部项目与会话，不包含桌面端数据。
- 重建边界（已确认）：IDE 界面独立设计，可靠的数据能力复用。

## 登录故障

用户报告：安装后重启，会出现账户登录错误。此问题纳入本次重构的前置排查与验收范围。

- 重启对象：用户确认重启 IDE 和重启电脑后均会触发。
- 已收到错误截图：`Error Loading Models`；`loadCodeAssist` 请求在向 `oauth2.googleapis.com/token` 发起请求时，TCP 443 连接超时（`connectex`）。
- 目前确认的故障表现是模型加载失败及 OAuth 服务连接超时，尚无凭据失效的证据。完整安装与触发步骤仍待核实。
- 先建立能识别相同故障的复现或观测信号，再定位原因；尚未确认与安装、配额请求或其他功能的因果关系。
- 验收需要覆盖安装后冷启动与重复启动，确认原生账户登录可用；不得通过重置账户数据掩盖故障。

### 2026-11-15 只读连通性观测

- 对 OAuth 与 Cloud Code 服务域名发出不带凭据的 `HEAD /` 探测：显式直连均在 8 秒内未完成；显式使用当前系统已配置的本地 HTTP 代理时，两者均约 1 秒内返回 HTTP 404。
- HTTP 404 在这里仅证明服务可达，不代表认证、模型加载或 API 业务请求成功。
- 当前观测到系统代理已启用，但进程、用户和机器级代理环境变量均未设置，WinHTTP 使用直连；尚未确认 IDE 原生请求实际采用哪条网络路径。
- 尚未在 IDE 原生请求路径建立可重复的故障与修复对照，不能据此认定扩展、安装器或某个代理配置是根因。
